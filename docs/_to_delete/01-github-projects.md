# GitHub Projects (Table view)
## Copy ✅
- Table + side panel on row click: dense list stays visible while inspecting one record — closest match to our Register + Detail Panel.
- Fields (column) chooser via menu; hide never deletes.
- Export view data = exports the CURRENT VIEW (their .tsv) — same law as ours.
- Keyboard-first navigation.
## Don't copy ❌
- Saved views as tabs (our deviation: none).
- `field:value` query filter syntax (engineer-oriented; our users are Excel-heritage).
- Group-by / slice panels (workflow features; our registers stay flat).
