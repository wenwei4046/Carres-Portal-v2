lie about their own date.

## Why they were retired

**8,999 lines held eight cards of open work.** Every chat walked past forty shipped cards to
find what was left, so every chat skipped, and what a chat skips it re-invents. The measured
cost on 2026-08-05: a planning session spent four rounds designing an item-outcome picker that
had been live since 2026-07-27, because it was reading a previous chat's notes instead of the
page.

```
Done work and to-do work may never live in the same file.
A MASTER is overwritten, never versioned. Git history is the archive.
Documents do not carry history.
```
