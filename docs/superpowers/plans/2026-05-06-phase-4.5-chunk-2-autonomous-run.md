## §5 — Failure protocol (when a subagent reports BLOCKED)

If any task hits BLOCKED after 3 subagent attempts OR an unexpected scope expansion:

1. **STOP** the autonomous run immediately. Do not attempt further tasks.
2. **Commit any in-progress work** on a WIP branch off `main` named `wip/chunk-2-blocked-{TASK_ID}` so Loo can inspect:
   ```bash
   git checkout -b wip/chunk-2-blocked-{TASK_ID}
   git add -A
   git commit -m "wip(chunk-2): blocked at {TASK_ID} — see status report"
   git checkout main
   ```
3. **Save a checkpoint** via `/context-save`:
   - Title: `phase-4.5-chunk-2-BLOCKED-{TASK_ID}`
   - Summary: what task, what blocked, what was tried (3 attempts each)
   - Remaining work: tasks `{TASK_ID}` through `T41` still TODO
   - Recommendation: 2-3 candidate next steps for Loo to pick
4. **Write structured status to `docs/superpowers/plans/2026-05-06-phase-4.5-chunk-2-blocked-status.md`**:
   ```
   STATUS: BLOCKED
   TASK: {TASK_ID} ({TASK_TITLE})
   ATTEMPTS: 3 (or N)
   ROOT CAUSE: <short>
   ATTEMPTED: <bullet list of each attempt's approach + failure mode>
   RECOMMENDATION: <ranked options>
   COMMITS LOCAL: <list>
   WIP BRANCH: wip/chunk-2-blocked-{TASK_ID}
   LAST CHECKPOINT: <filename>
   ```
5. **Do NOT push.** Loo will see the status when he checks in the morning.
