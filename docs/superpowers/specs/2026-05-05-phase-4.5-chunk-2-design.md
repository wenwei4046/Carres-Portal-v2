## 3. Per-leg LP schema split (binding decision land here, OQ3 from Chunk 1)

### 3.1 Status from Chunk 1

Chunk 1 §0.5 OQ3 chose **option (b)**: Chunk 1 = same LP both legs of one PO. Real per-leg split deferred here.

### 3.2 Decision matrix (TBD — fleshed out post-Chunk-1)

| Option | Schema shape | Migration cost | UI/RPC churn |
|---|---|---|---|
| **(a)** Two columns on PO | `procurement_partner_id` + `delivery_partner_id` on `purchase_orders` | ALTER TABLE additive; backfill `procurement_partner_id := delivery_partner_id` for existing rows | All v3 RPCs that read `delivery_partner_id` need to choose which leg they care about |
| **(b)** Move customer-leg fields to thread | `purchase_orders.delivery_partner_id` becomes procurement-only; new `order_supplier_threads.delivery_partner_id` for customer-leg | More invasive; threads migration needs to copy from PO; aligns with C1.5 "PO scope = us → supplier ONLY" | RFD/accept timestamps also move to thread (cleaner) |
| **(c)** Hybrid: PO keeps procurement, thread has delivery, with denorm | PO has procurement_partner_id; thread has delivery_partner_id; denormalized indices for fast queries | Maximum flexibility but maximum complexity | Most code changes |

**Default (TBD)**: option (b) likely best fit — matches C1.5 scope rule + cleaner thread-as-customer-state model. But wait until Chunk 1 ships to see if RFD/accept timestamps on PO (added in Chunk 1's 0044) feel awkward.

### 3.3 Migration path (TBD)

- Migration NNNN: ADD COLUMNS on threads
- Migration NNNN+1: data migration (copy from PO to thread for existing rows)
- Migration NNNN+2: DROP COLUMNS from PO (only after RPC + UI rewritten to read from thread)

Irreversible. Carry-forward `phase-4.5-procurement-vs-delivery-partner-field-split` lives here.

## 6. M4.6 — PO COGS source (skeleton)

### 6.1 Schema delta

```sql
ALTER TABLE purchase_order_lines
  ADD COLUMN cost numeric(14,2),
  ADD COLUMN cost_source cost_source_enum;

CREATE TYPE cost_source_enum AS ENUM ('hand_entered', 'prev_po', 'system_suggested');
```

### 6.2 UI flow

- CreatePOModal: cost field on each line + dropdown "Source" (hand / prev / suggested)
- "Suggested" computed from last received PO line for same SKU
- Finance reconciliation reads `cost_source` for audit trail
