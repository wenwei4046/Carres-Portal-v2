三个面板，三个清楚的用途

Calendar 看日期；My Work 看我现在要处理的数量；Activity 看最近发生的变化。

PROPOSAL / NOT APPROVED
这是设计评审稿，所有姓名、编号和数量均为虚构。新增文案和组件仍待审核。此页面不连接业务系统，也不会保存任何记录。示例编号遵循已批准格式：SO 四位、SUB 五位，版本号紧接编号；这不代表新的 SO 编号生成规则已经实现。实际面板应读取已保存的单据编号，历史编号保持原样。
折叠入口：Calendar / My Work / Activity；统一蓝色选中。My Work 徽标 = Missed + Today。

现状的主要问题

  • Calendar 读取失败仍可能显示没有活动。
  • My Work 失败提示与图标的零值信息不一致。
  • Activity 类型筛选显示内部词；关键变化被截断。
  • Calendar 记录没有入口；Activity 点击后暗中切换范围。

建议的取舍

  • 先说明范围和数据时间，再显示数量。
  • My Work 保留已批准的 Missed / Today 数量入口。
  • Activity 保持 Sales Orders 范围；完整 History 在原单据。
  • Calendar 和 Activity 窄屏复用抽屉；My Work 不新增小任务面板。
