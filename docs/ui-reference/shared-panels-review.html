员工怎样用？

客户来电 → 搜电话/姓名/单号 → 选客户 → 查订单和记录 → 需要处理时打开原单据。问日期时 → Calendar 选日 → 点模块摘要。想知道变化原因时 → Activity 查谁改了什么。

范围与取舍

客户记录只汇总有依据的关联；同名不自动合并。Activity 包含权限内同事的变化，不是所有登录者都能看公司全部资料，也不是员工在线状态。

窄屏建议从现有菜单进入完整客户搜索页；Calendar / Activity 使用原模块日程和对象 History。这个新客户入口位置仍待审核。
