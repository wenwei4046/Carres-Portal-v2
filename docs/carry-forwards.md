- `order-payments-ledger-has-no-reader` — **C5 (2026-07-27), the seam C5's own premise did not account for.** C5 correctly made `orders.paid` the money truth and took every gate off the `order_payments` ledger. Service Case S4 (2026-07-27, 0298): `service_cases` records WHEN a case was opened (`opened_at`) but never when it was CLOSED. The status carries `is_closed` and nothing timestamps the transition, so the deadline clock can only be switched off for a closed case — it cannot say whether that case finished inside its 14 working days. **This blocks two of S5's own asks**: "avg days to close" and "SLA hit rate" are not computable for any case already closed, including every case closed before the column exists. **Firm fix, and it belongs in S5's migration**: add `closed_at timestamptz` set by a trigger on the transition INTO a closed status (the 0293 trigger already computes exactly that transition and can carry it), plus a one-time backfill from `updated_at` for the rows on file, flagged as approximate. Doing it in S5 rather than S4 is deliberate — S4 needs no such column and inventing one it does not read would be a field nobody maintains.
