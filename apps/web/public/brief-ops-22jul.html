Carres Orders — 新做法 5 分钟

Team briefing · Wed 22 Jul 26 · 10:30(Jess 主持;听完才开始用)

1 · 你的一天 = 左边 QUEUES,四个动词

每张单右边的 NEXT 列告诉你下一步做什么;左边 QUEUES 就是这些动词的合计,点进去就是清单:

动词意思谁做
Order PO 红货还没跟供应商下单PO 值日者
Chase supplier 琥珀PO 下了,货还没进仓 → 催厂PO 值日者
Assign logistic还没派哪家车PIC(自己的单)
Chase logistic派了车、还没跟客人约好 slot → 催车PIC(自己的单)

Overdue = 过了答应客人的日子还没送到(结果);该追谁看那行 NEXT。Owing = 客人还欠钱(PIC 追)。

2 · PIC = 你的客人(人分单)

  • 每张单一个 PIC(你的头像 chip)。点右上自己的头像 = 只看自己的单。
  • 钱(Owing)和送(logistic)你追;客人打来问什么,你负责答。
  • 催客人/催车用系统的 Chase 按钮 → 一个对象一天一条合并消息,不要自己散弹发。

3 · PO 值日(货合买)— 7月 Shasha · 8月 Li Ching · 9月 Khor Yee

  • PO 全公司合开,永不按人拆。只有值日者(+管理层)能按 Raise PO。
  • 每逢周一 / 周四 = PO day:系统自动给值日者开 task + Orders 页出横幅 → 勾单 → Raise PO → 一个供应商一张卡 → 逐卡 Send。
  • 红字急单(deadline 掉进备货窗:床垫/床架 7 天 · 沙发 5 天)任何一天都要马上开,不等 PO day。
  • 供应商 WhatsApp 只有值日者一个声音。想知道货几时到 → 内部问值日者,不准自己去戳供应商。月底交接 = open PO 清单。

4 · 全自动规则(你不用管,但要知道)

  • 第一次登录 = 自动进 pool、自动分单。开账号是唯一人工步骤。
  • 10:00 前没上线,你的份额还在;10:00 后还没上线 = 系统当你今天缺席,单自动流给在场同事;你一登录自动流回。MC 不用报备系统,它自己懂。
  • away 勾只用于预先知道的长假;手动改派只有 Jess/管理层能做。
  • 做完的单按 Mark delivered 收掉——Delivered 的单永不再响。
