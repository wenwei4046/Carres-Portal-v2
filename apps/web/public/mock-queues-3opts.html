QUEUES 词汇对齐 — 3 案(数字为今日实况/示意)

你问的两个词,先给答案:Overdue = 过了答应客人的日子还没送到(结果,不指定追谁——该追谁看该行 NEXT);To book = 有 logistic 但还没约到送货 slot → 追 logistic;Waiting stock → 追 supplier。下面 3 案解决「同一件事在 QUEUES / NEXT / 详情页 Chase Now 用不同词」的问题。

A · 原词 + 追谁标注(最小改)

行名全部不动,每行前面挂 list Status 列同一套图标(RM$ 钱 · 箱 货 · 卡车 送),行尾灰字标「追谁」。学习成本零,但词还是两套。
