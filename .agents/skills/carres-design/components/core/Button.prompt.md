Flame/black/outline button set — use for every clickable action. Exactly ONE `hero` (flame) per page or block; all other primary actions are `primary` (black).

```jsx
<Button variant="hero">+ AutoCount</Button>
<Button variant="primary">Record payment</Button>
<Button variant="secondary">+ Master</Button>
<Button variant="danger">Cancel order</Button>
```

Variants: `hero` · `primary` · `secondary` · `ghost` · `danger`. Sentence case labels, never uppercase. Pass `icon` for a leading Lucide glyph.
